AaryaAI – Datenschutz · Privacy

Deutsch

AaryaAI ist eine Lern-App für Kinder. Es gibt keinen AaryaAI-Server, keine Werbung, kein Tracking und keine Analyse-Tools.

  • Der Lernfortschritt (Name des Kindes, Punkte, Sterne, Einstellungen) wird nur im Browser des Geräts gespeichert.
  • Optional wählen Eltern eine Speicherdatei auf ihrem Gerät.
  • Optional verbinden Eltern ihr eigenes Google Drive. Die App nutzt dann nur den versteckten App-Ordner (Berechtigung drive.appdata): Sie kann keine anderen Dateien sehen oder ändern. Die Daten gehen direkt vom Browser zu Google; AaryaAI erhält sie nie. Trennen jederzeit im Elternbereich; die Freigabe lässt sich auch unter myaccount.google.com/permissions entfernen.
  • Spracheingabe und Vorlesen nutzen die Sprachfunktionen des Browsers bzw. Betriebssystems.

English

AaryaAI is a learning app for children. There is no AaryaAI server, no ads, no tracking and no analytics.

  • Learning progress (child's name, points, stars, settings) is stored only in the browser on the device.
  • Optionally, parents choose a save file on their device.
  • Optionally, parents connect their own Google Drive. The app then uses only the hidden app-data folder (scope drive.appdata): it cannot see or change any other file. Data goes directly from the browser to Google; AaryaAI never receives it. Disconnect at any time in the parent area, or remove access at myaccount.google.com/permissions.
  • Speech input and read-aloud use the speech features of the browser or operating system.
